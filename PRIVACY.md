# Privacy

These acceptance apps use synthetic Markdown and a counter. They write only
their own local test note. They do not sign in, access personal accounts,
transmit app data, collect analytics, or start an AI model automatically.

The optional app tool runs these same local checks when requested. The host
API demonstration reads public API metadata with `runtime.describe`.
GitHub records public source, releases, and artifact provenance.

Uninstalling the app removes its local app data. This repository has no app
backend and holds no user credentials.
